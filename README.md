### About Me

Technology has interested me for as long as I can remember. Around **2005**, I began exploring computers and digital systems by creating and experimenting with alternative servers for online games.

I enjoy understanding how things work, learning through technical challenges, and turning ideas into functional projects. Automation is a recurring interest: finding practical ways to simplify tasks, connect systems, and solve problems.

AI-assisted tools have changed how I explore technology. I use them to **learn while building**, investigate how software works, test ideas faster, and overcome technical barriers.

Professionally, I work as a **manager in Public Administration**. This GitHub is a personal space for technological experimentation, hands-on learning, and independent projects.

### Statistics & Streak Analytics
A mathematically rigorous contribution and streak calculation engine built in Python 3.12 without external dependencies. Features current-day grace rules, canonical UTC/São Paulo timezone reconciliation, genuine date-membership chart highlighting, and static accessibility fallbacks.

    <li><b>Recent Activity Series</b>: 35-day discrete daily volume with exact date-membership highlighting.</li>
