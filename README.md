### About & Positioning

I operate within **Public Administration**, focusing on operational capability and process transformation through automation, data engineering, and agentic artificial intelligence. With a foundational background in **Law**, I approach administrative workflows through structural rules, regulatory constraints, and process mechanics—translating statutory requirements and real operational demands into automated digital solutions.

My technical focus spans:
- **Applied AI & Agentic Systems**: Designing deterministic workflows and collaborating with autonomous coding agents (Codex, Google Antigravity, Orca ADE, Hermes) for continuous software delivery.
- **Workflow Automation & Systems Integration**: Constructing event-driven pipelines, RESTful integrations, and webhook orchestration that remove operational bottlenecks.
- **Data Engineering & Reliability**: Developing reproducible data pipelines, verified contribution analytics, and resilient self-hosted platforms.

### Featured Work & Autonomous Implementations

#### 🐜 Langton's Ant × Real GitHub Contributions
An original 2D cellular automaton implementation where the real contribution calendar initializes the automaton's binary state on an infinite virtual plane. Rather than a purely cosmetic overlay, the ant executes authentic RL rules (turn 90° right on 0, 90° left on 1, flip state, advance) rendered via declarative SMIL SVG animations.

    <li><b>Seed Condition</b>: Evaluates <code>contributionCount &gt; 0 &rarr; state 1</code>; cell intensity preserves GitHub quartile shades.</li>
    <li><b>Deterministic Horizon Discovery</b>: Simulates 10,000 steps deterministically to select optimal starting vectors.</li>

#### 📊 Self-Hosted GitHub Contribution & Streak Analytics
A mathematically rigorous contribution and streak calculation engine built in Python 3.12 without external dependencies. Features current-day grace rules, canonical UTC/São Paulo timezone reconciliation, genuine date-membership chart highlighting, and static accessibility fallbacks.
